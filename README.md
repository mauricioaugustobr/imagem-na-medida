# Imagem na Medida

Editor de imagens no navegador para recortar e exportar em PNG nos formatos de posts, stories, vídeos ou dimensões personalizadas.

## Usar localmente

Na pasta do projeto, execute `python3 -m http.server 8000` e abra `http://localhost:8000`. Escolha uma imagem JPG, PNG ou WebP, ajuste o tamanho e o enquadramento e clique em **Baixar imagem**. O processamento da imagem ocorre no navegador.

Funciona como site estático: basta publicar os arquivos `index.html`, `style.css` e `app.js`.
